# Media

Put screenshots, diagrams and videos in the folder for each experience or project:

```
experience/technology-mindz/   architecture.svg (Excalidraw export)
experience/beema-ghar/         cover.png, screenshots
experience/vigilronyx/         (nothing confidential, so normally empty)
projects/solarchain/           demo.mp4 / poster.jpg (or use a YouTube link)
projects/medifix/              screenshots
projects/park-here/            screenshots
projects/fam-sync/             concept art only, clearly labelled
```

Then reference each file from `src/content/*.ts` with a path starting at `/media/…`.
See the main README for details.
